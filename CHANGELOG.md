### Added

- **Scam Fire Drills** (Phase 3) — personalized scam simulations with debrief and Resilience Score
- **Live Call Guardian** (Phase 4) — real-time 5-stage pipeline detection over WebSocket, Memory Handshake, voice authenticity
- **Scammer Hunter** (Phase 5) — AI honeypot, IOC extraction, Neo4j Scam Graph with weather-map UI
- **Zero-install Telegram bot** (Phase 2) — forward text/voice/screenshot, get a verdict in seconds
- Analysis engine for text, URL, image, and voice inputs with pluggable LLM providers (Groq, Gemini, Ollama)
- Next.js landing, dashboard, drill, guardian, and graph pages
- FastAPI backend with Supabase + Neo4j integrations
- MIT license, contributing guide, code of conduct, security policy
- CI workflow (backend/bot pytest + ruff, frontend eslint + next build)
- Architecture diagrams and product screenshots in `docs/assets/`
- 60-second launch video (`brag-output/brag.mp4`)
